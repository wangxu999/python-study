# Python 变量

## 一句话结论

变量是程序中用来存储单个数据的容器。通常会把经常发生变化的数据存储在变量中，通过变量名可以读取或更新这个值。

## 定义格式

```python
变量名 = 变量的值
```

等号 `=` 表示赋值：把右边的值保存到左边的变量名中。

```python
name = "小王"
age = 18
score = 95.5
is_logged_in = True
```

## 使用变量

定义变量后，可以直接使用变量名：

```python
name = "小王"
print(name)
```

输出：

```text
小王
```

变量的值也可以更新：

```python
score = 80
score = 90
print(score)
```

输出：

```text
90
```

后一次赋值会覆盖前一次的值。

## 变量命名规则

- 只能由字母、数字和下划线 `_` 组成。
- 不能以数字开头。
- 不能使用 Python 关键字，例如 `if`、`for`、`class`。
- 区分大小写，`name` 和 `Name` 是两个不同的变量。
- 建议使用有意义的小写英文名称，多个单词用下划线连接，例如 `user_name`、`total_price`。

```python
user_name = "小王"   # 推荐
total_price = 99.9   # 推荐
```

## 易错点

- [ ] 变量名以数字开头。
  - 错误示例：`1name = "小王"`
  - 正确做法：`name1 = "小王"`
- [ ] 使用中文符号或把等号写成冒号。
  - 正确做法：使用英文半角等号 `=`。
- [ ] 使用尚未定义的变量。
  - 正确做法：先定义变量，再使用变量名。
- [ ] 将 `=` 和 `==` 混淆。
  - 正确做法：`=` 用于赋值，`==` 用于比较两个值是否相等。
