# Python 注释

## 一句话结论

注释用于解释代码的目的、原因和使用方式，帮助自己和他人理解代码；Python 运行时通常不会执行以 `#` 开头的注释内容。

## 核心概念

- 单行注释：使用 `#`，从 `#` 开始到该行结束都是注释。
- 行尾注释：写在代码后方，用于简短说明，不应挤占可读性。
- 文档字符串：使用三引号 `"""` 或 `'''`，通常写在模块、函数、类的第一行，用于说明用途、参数和返回值。
- 多行说明：连续多行都加 `#`。三引号只有在作为文档字符串被读取时才适合用于说明；不要把普通三引号字符串误认为通用注释。

## 语法和示例

### 单行注释

```python
# 这是单行注释
print("你好")
```

输出：

```text
你好
```

### 行尾注释

```python
age = 18  # 用户年龄，单位是岁
```

行尾注释适合补充很短的信息。复杂逻辑应写在代码上方，避免一行过长。

### 函数文档字符串

```python
def calculate_total(price: float, count: int) -> float:
    """计算商品总价。

    参数：
        price: 单价。
        count: 数量。

    返回：
        商品总价。
    """
    return price * count


print(calculate_total(19.9, 2))
```

输出：

```text
39.8
```

## 注释应该写什么

- 解释为什么这样做，而不是重复代码已经表达的意思。
- 说明业务规则、单位、时间格式、边界条件或容易误解的处理。
- 标注待办事项时写清下一步，而不是只写 `TODO`。
- 为公共函数、类和模块补充文档字符串，说明如何使用。

## 不推荐的写法

```python
# 将 i 加 1
i = i + 1
```

这条注释只是重复代码，应删除。下面这种说明更有价值：

```python
# API 的页码从 1 开始，因此请求前需要加 1。
page_number = index + 1
```

## 易错点

- [ ] 以为三引号一定是注释。
  - 原因：三引号本质上是字符串；只有放在模块、函数或类开头时，通常作为文档字符串使用。
  - 正确做法：普通注释使用 `#`；需要说明函数或类时使用文档字符串。
- [ ] 注释和代码不一致。
  - 原因：修改代码时忘记同步修改注释。
  - 正确做法：每次修改逻辑后检查相关注释，不准确的注释比没有注释更容易造成误解。
- [ ] 用注释隐藏废弃代码。
  - 原因：担心以后需要恢复。
  - 正确做法：删除不需要的代码，Git 会保留历史版本；只保留正在使用的代码。
