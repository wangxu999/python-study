# Python 标识符

## 一句话结论

标识符是程序员在代码中为变量、函数、类等元素所起的名字。变量名、函数名和类名都属于标识符。

## 变量定义回顾

```python
变量名 = 变量的值
```

其中左侧的变量名就是一个标识符。

```python
age = 18
user_name = "小王"
```

`age` 和 `user_name` 都是标识符。

## 命名规则 规定

1. 只能包含字母 `a-z`、`A-Z`、数字 `0-9` 和下划线 `_`。
2. 不能以数字开头。
3. 不能使用 Python 关键字，例如 `True`、`False`、`None`、`and`、`or`、`if`、`else`、`elif`、`for`、`while` 等。
4. 严格区分大小写，例如 `age`、`Age`、`AGE` 是三个不同的标识符。

## 合法和非法示例

| 写法 | 是否可用 | 原因 |
| --- | --- | --- |
| `age` | 可以 | 由字母组成 |
| `user_name` | 可以 | 使用下划线连接多个单词 |
| `score2026` | 可以 | 数字不在开头 |
| `_count` | 可以 | 下划线可以在开头 |
| `2age` | 不可以 | 不能以数字开头 |
| `user-name` | 不可以 | 连字符 `-` 不是标识符允许的字符 |
| `user name` | 不可以 | 不能包含空格 |
| `if` | 不可以 | `if` 是 Python 关键字 |
| `True` | 不可以 | `True` 是 Python 保留字 |

## 命名建议

规则决定“能不能用”，命名建议决定“好不好懂”。

### 变量命名规范

1. 见名知意：变量名应表达它保存的数据用途，例如 `user_age` 比 `a` 更容易理解。
2. 多个部分使用下划线连接：例如 `total_price`、`student_name`。
3. 英文字母全部小写：变量名通常使用小写字母；多个单词之间用下划线分隔。

- 变量和函数通常使用小写字母加下划线：`user_name`、`total_price`、`calculate_total()`。
- 类通常使用大驼峰命名：`Student`、`OrderItem`。
- 名称应表达用途，避免使用没有意义的 `a`、`b`、`x1`，循环中的临时计数变量除外。
- 不要使用 `list`、`str`、`type` 等内置名称作为变量名，以免覆盖 Python 自带功能。

```python
user_age = 18
total_price = 99.9


class Student:
    pass
```

## 易错点

- [ ] 将“关键字”误写为“键字”。
  - 正确术语：关键字。
- [ ] 认为 `age`、`Age`、`AGE` 是同一个变量。
  - 正确做法：Python 区分大小写，它们是三个不同的标识符。
- [ ] 用短横线 `-` 连接单词。
  - 错误示例：`user-name`。
  - 正确做法：使用下划线，写成 `user_name`。
- [ ] 用关键字或保留字命名。
  - 正确做法：换成描述用途的名称，例如把 `if` 改为 `condition`。
