# Python 运算符

## 一句话结论

运算符用于对数据进行计算、比较或赋值。本笔记先整理常用的算术运算符和赋值运算符。

## 常用算术运算符

| 运算符 | 描述 | 示例 | 结果 |
| --- | --- | --- | --- |
| `+` | 加法 | `1 + 5` | `6` |
| `-` | 减法 | `8 - 3` | `5` |
| `*` | 乘法 | `3 * 8` | `24` |
| `/` | 除法 | `10 / 5` | `2.0` |
| `//` | 整除或向下取整除法 | `10 // 3` | `3` |
| `%` | 取余或求模 | `10 % 3` | `1` |
| `**` | 幂或指数 | `10 ** 3` | `1000` |

## 基本示例

```python
print(1 + 5)    # 6
print(8 - 3)    # 5
print(3 * 8)    # 24
print(10 / 5)   # 2.0
print(10 // 3)  # 3
print(10 % 3)   # 1
print(10 ** 3)  # 1000
```

## 除法、整除和取余

这三个运算符都与“除法”有关，但用途不同。

```python
dividend = 10
divisor = 3

print(dividend / divisor)   # 3.3333333333333335，普通除法
print(dividend // divisor)  # 3，整除后向下取整
print(dividend % divisor)   # 1，余数
```

对于整数相除，`/` 的结果始终是 `float`。例如 `10 / 5` 的结果是 `2.0`，不是 `2`。

`//` 的结果不一定总是 `int`：如果其中一个操作数是浮点数，结果通常也是 `float`。

```python
print(10 // 3)    # 3，int
print(10.0 // 3)  # 3.0，float
```

对于正数，整除可以理解为舍去小数部分；更准确地说，`//` 会向负无穷方向取整。

```python
print(-10 // 3)  # -4
```

## 取余的常见用途

取余 `%` 可以判断一个数能否被另一个数整除。

```python
number = 10

if number % 2 == 0:
    print("偶数")
else:
    print("奇数")
```

当余数为 `0` 时，表示可以整除。

## 幂运算

`**` 表示乘方，而不是两个星号的普通文本。

```python
print(2 ** 3)  # 8，即 2 的 3 次方
print(5 ** 2)  # 25，即 5 的平方
```

## 运算优先级

Python 会先计算幂运算，再计算乘、除、整除、取余，最后计算加减。可以使用圆括号 `()` 明确控制计算顺序。

```python
print(1 + 2 * 3)      # 7，先算 2 * 3
print((1 + 2) * 3)    # 9，先算括号中的 1 + 2
```

## 赋值运算符

赋值运算符用于将一个值，或表达式计算后的结果，保存到变量中。赋值时会先计算右侧的内容，再把结果赋给左侧变量。

```python
num = 1 + 2
print(num)  # 3
```

这里的 `=` 表示赋值：将右边 `1 + 2` 的计算结果 `3` 保存到左边变量 `num` 中。

### 常用赋值运算符

| 运算符 | 描述 | 示例 | 等效写法 |
| --- | --- | --- | --- |
| `=` | 赋值 | `num = 10` | 将右侧值赋给左侧变量 |
| `+=` | 加法赋值 | `num += 2` | `num = num + 2` |
| `-=` | 减法赋值 | `num -= 2` | `num = num - 2` |
| `*=` | 乘法赋值 | `num *= 2` | `num = num * 2` |
| `/=` | 除法赋值 | `num /= 2` | `num = num / 2` |
| `%=` | 取模赋值 | `num %= 2` | `num = num % 2` |
| `//=` | 整除赋值 | `num //= 2` | `num = num // 2` |
| `**=` | 幂赋值 | `num **= 2` | `num = num ** 2` |

### 基本示例

```python
num = 10

num += 2
print(num)  # 12

num *= 3
print(num)  # 36

num //= 5
print(num)  # 7
```

赋值运算符也可以用于字符串：

```python
message = "你好"
message += "，Python"

print(message)
```

输出：

```text
你好，Python
```

## 比较运算符

比较运算符也称为关系运算符，用于比较两个值之间的关系。Python 会计算运算符两边的表达式，然后返回一个布尔值：`True` 表示比较关系成立，`False` 表示比较关系不成立。

| 运算符 | 描述 | 示例 | 结果说明 |
| --- | --- | --- | --- |
| `==` | 等于 | `a == b` | 判断 `a` 是否等于 `b` |
| `!=` | 不等于 | `a != b` | 判断 `a` 是否不等于 `b` |
| `>` | 大于 | `a > b` | 判断 `a` 是否大于 `b` |
| `>=` | 大于等于 | `a >= b` | 判断 `a` 是否大于或等于 `b` |
| `<` | 小于 | `a < b` | 判断 `a` 是否小于 `b` |
| `<=` | 小于等于 | `a <= b` | 判断 `a` 是否小于或等于 `b` |

### 基本示例

```python
a = 10
b = 5

print(a == b)  # False
print(a != b)  # True
print(a > b)   # True
print(a >= b)  # True
print(a < b)   # False
print(a <= b)  # False
```

### 比较表达式的结果

比较表达式本身的结果是布尔值，因此可以保存到变量或直接用于后续的条件判断。

```python
score = 90
is_passed = score >= 60

print(is_passed)
```

输出：

```text
True
```

### 连续比较

Python 支持将范围比较写在同一个表达式中。

```python
age = 18
print(0 <= age <= 120)  # True
```

上面的写法等效于：

```python
print(age >= 0 and age <= 120)
```

## 逻辑运算符

逻辑运算符用于连接多个条件表达式，并得到最终的判断结果。对布尔值进行运算时，结果也是布尔值。

| 运算符 | 描述 | 结果规则 |
| --- | --- | --- |
| `and` | 逻辑与，并且 | 两边都为 `True` 时，结果才为 `True` |
| `or` | 逻辑或，或者 | 两边只要有一边为 `True`，结果就为 `True` |
| `not` | 逻辑非，取反 | `True` 变为 `False`，`False` 变为 `True` |

### 真值表

| `a` | `b` | `a and b` | `a or b` | `not a` |
| --- | --- | --- | --- | --- |
| `True` | `True` | `True` | `True` | `False` |
| `True` | `False` | `False` | `True` | `False` |
| `False` | `True` | `False` | `True` | `True` |
| `False` | `False` | `False` | `False` | `True` |

### 基本示例

```python
age = 18
has_ticket = True

print(age >= 18 and has_ticket)  # True，年龄和车票条件都满足
print(age < 18 or has_ticket)    # True，只要其中一个条件满足即可
print(not has_ticket)            # False，对 True 取反
```

### 在条件判断中使用

```python
score = 85
is_present = True

if score >= 60 and is_present:
    print("成绩合格且已出勤")
```

### 短路特点

`and` 和 `or` 会从左到右判断，并在结果已确定时停止计算右侧表达式：

- 对 `and`：左侧为 `False` 时，整体一定为 `False`，右侧不会再计算。
- 对 `or`：左侧为 `True` 时，整体一定为 `True`，右侧不会再计算。

```python
age = 0

# age != 0 为 False，右侧不会执行，因此不会出现除以 0 的错误。
print(age != 0 and 100 / age > 1)
```

## 易错点

- [ ] 认为 `/` 得到整数结果。
  - 正确做法：`/` 的结果是浮点数，例如 `10 / 5` 得到 `2.0`。
- [ ] 将 `//` 和 `/` 混淆。
  - 正确做法：`/` 保留除法结果，`//` 进行向下取整除法。
- [ ] 将 `%` 误认为百分号。
  - 正确做法：在算术运算中，`%` 表示取余；在字符串格式化中还有其他用途。
- [ ] 使用 `^` 表示乘方。
  - 正确做法：Python 中乘方使用 `**`，`^` 是按位异或运算符。
- [ ] 除数为 `0`。
  - 正确做法：任何除法、整除或取余都不能以 `0` 作为除数，否则会报错。
- [ ] 将 `=` 和 `==` 混淆。
  - 正确做法：`=` 用于赋值，`==` 用于比较两个值是否相等。
- [ ] 在变量未定义时直接使用 `+=`、`-=` 等赋值运算符。
  - 正确做法：先定义变量，例如先写 `num = 0`，再写 `num += 1`。
- [ ] 将 `>=`、`<=` 写反，或误以为 `<=` 只表示小于。
  - 正确做法：`>=` 表示大于或等于，`<=` 表示小于或等于。
- [ ] 以为比较运算符返回比较后的数值。
  - 正确做法：比较运算符返回 `True` 或 `False`。
- [ ] 将 `and` 理解为“只要一个条件成立”。
  - 正确做法：`and` 两边条件必须同时成立。
- [ ] 将 `or` 理解为“两边必须同时成立”。
  - 正确做法：`or` 只要至少一个条件成立即可。
- [ ] 忘记 `not` 的作用是取反。
  - 正确做法：`not True` 为 `False`，`not False` 为 `True`。
- [ ] 用 `&`、`|`、`!` 代替 `and`、`or`、`not`。
  - 正确做法：条件逻辑判断使用 Python 关键字 `and`、`or`、`not`。
